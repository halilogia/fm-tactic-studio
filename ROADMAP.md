# 🗺️ FM Tactic Studio — Roadmap

## Milestone 1.0 (Current Stable)
- [x] Reverse-engineer Sports Interactive `.fmf` archive container and Zstandard TOC.
- [x] Build FastAPI backend to parse `.fmf` files and list tactic metadata.
- [x] Create 2D interactive tactical pitch with drag & drop player nodes.
- [x] Full Football Manager role and duty mapping (GK, DEF, MID, ATT).
- [x] Responsive layout with vertical scroll and zoom optimizations.
- [x] Desktop integration (Electron shell, custom `.ico` icon, desktop shortcut).
- [x] SRP modularization (`styles.css`, `formations.js`, `pitch.js`, `app.js`).
- [x] Privacy isolation (Dynamic folder detection, git-ignored local configs).
